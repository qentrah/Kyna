# Kyna 1.0.16 release candidate

The prepared release is built from `624eb7eb43cb47060766556a57cf22de42cd99be`. PR #6 supplies the safety/native-library upgrade; PR #7 adds repository generation, app icons, declared assets and portable Linux BLAS dispatch. npm publication belongs to the owner.

Kyna retains its C++ compiler, existing HIR/MIR/bytecode pipeline and VM. Checked import/export contracts preserve inferred bindings, generics, nullability and private type dependencies without exposing private names. Type-only syntax has no runtime execution. Export caches include transitive contracts and compiler/checker fingerprints. Exact numeric comparison, overflow and control-flow regressions preserve evaluation behavior across supported engines.

C ABI 2 native packages provide typed exports, rooted callbacks, resource lifetimes, thread validation, runtime conversions and exception translation. `ky install` verifies native archives; `ky build` packages applications and locally authored C++ modules. Optional Qt Quick, CGAL and mlpack packages provide GUI, geometry and regression operations.

`ky generate repo my-app` creates a runnable MIT-licensed Git repository. Explicit `--github qentrah/my-app` also creates and pushes a public repository. Apps can set `guiIcon(path)` and declare `[build].assets`; staging rejects escaping source/asset symlinks and removes rejected partial output. Linux x86_64 ML packages use runtime CPU dispatch, with an older CPU-kernel parity check in CI.

[Kyna Music](https://github.com/qentrah/kyna-music) is the separate native application example, with Kyna application behavior, a typed Qt adapter, real local audio playback, original assets, screenshots, a working video and a build tour. Its [Windows x86_64, Linux x86_64 and macOS ARM64 workflow](https://github.com/qentrah/kyna-music/actions/runs/38350021366) passes at `72a79fa`.

## Verification and assets

- [Core platform CI](https://github.com/qentrah/Kyna/actions/runs/38353269654): Windows/macOS/Linux builds, compiler/tooling tests and installers; Linux Debug and ASan/UBSan with leak detection.
- [Complete native PR matrix](https://github.com/qentrah/Kyna/actions/runs/38353269961): all five desktop native targets and Android ARM64 cross-compilation.
- [Linux native portability](https://github.com/qentrah/Kyna/actions/runs/38353267268): complete native package smoke and C++/Kyna regression with `OPENBLAS_CORETYPE=NEHALEM`.
- [Complete release rehearsal](https://github.com/qentrah/Kyna/actions/runs/38353364260): five CLI/native targets, Android ARM64 cross-compilation, VSIX, npm adapter tests/packing and verified release assembly.

The desktop release matrix is Linux x86_64/ARM64, macOS x86_64/ARM64 and Windows x86_64. Application smoke, native installation and `ky build` run after relocation with original SDK paths removed. Archives include runtime dependencies, Qt plugins/QML/framework resources, notices, corresponding Qt sources and binary inventories. Bash, PowerShell and npm consume the same native archives and SHA256SUMS.

`RELEASE-CANDIDATE.json` records the exact source commit and verification run. `SHA256SUMS` covers every other asset. Manual rehearsal assembles `verified-release-candidate` without publishing or creating a tag. Draft preparation uploads these verified assets and compares GitHub's returned digests against the local candidate before completion. A published release is never replaced.

## Publication gates

This remains a draft. Production signing/notarization credentials, the stable-release approval variable and final dependency-license clearance are pending. npm publication remains with the owner.

Android cross-compilation is separate from application smoke. [Actual recordings](../videos/README.md) include an Android 14 ARM64 emulator running on a physical Mac.
