# Kyna 1.0.16 release candidate

Prepared from PR #6. This release remains a draft while final platform CI and
production distribution gates are pending. npm publication belongs to the owner.

Kyna keeps its C++ compiler and VM and adds checked module/type contracts,
compiler-version-aware user-local export caching that ignores dependency-provided contracts, exact numeric comparisons and stronger
switch/control-flow diagnostics. Exported interfaces retain checked private
type dependencies and generic nullability while keeping private names inaccessible. Type intern pools own their allocations and release them at
shutdown while preserving stable pointer identity. The CLI groups help and reports stable diagnostic
codes; the VS Code extension handles unsaved dependencies and native package
navigation with diagnostics at their actual source locations.

Typed C ABI 2 native packages support rooted callbacks, explicit resource lifetime,
validated conversions and translated C++ failures. Qt application/bridge lifetimes and UI-thread embedding contracts are checked.
Verified native installation
and `ky build` package applications and authored C++ modules. Optional libraries
provide Qt Quick GUI, CGAL hull/mesh operations and mlpack regression.

Portable archives retain runtime dependencies, Qt plugins/QML/framework resources,
licenses, corresponding Qt source archives and binary inventories. Bash, PowerShell and npm consume matching
archives and SHA256SUMS. Stable CLI/native artifacts require signature verification
and accepted notarization; release assembly waits for all platform package jobs.

The desktop release matrix is Linux x86_64/ARM64, macOS x86_64/ARM64 and Windows
x86_64. A target is supported only after its application smoke passes. Android
ARM64 cross-compilation and its application lifecycle gate remain separate.
The Android smoke APK uses an ephemeral test key, not a production signing key.

Local verification passes 57 Debug CTests, 57 Release CTests and 62 optional-library CTests, focused
extension/npm tests and relocated application/install/build smoke. All 57 Address/Undefined Behavior sanitizer CTests passed after the final compiler/cache changes. Actual desktop and Android emulator recordings:
https://github.com/qentrah/Kyna/tree/codex/kyna-safety-native-libraries/docs/videos

Core portable CI (Linux, macOS and Windows):
https://github.com/qentrah/Kyna/actions/runs/38116023806

Windows GUI execution, shutdown and consecutive embedded sessions pass after
the adapter image-residency fix. Complete native installation and SDK-isolated
relocation remain pending in the final matrix. Manual release rehearsals now
assemble all five CLI/native targets, Android, VSIX, owner-ready npm, installers
and an exact SHA256SUMS manifest into `verified-release-candidate`; they do not
publish or create a tag. Local release safety verification passes all 28 tests.

Prepared drafts receive verified assets before publication; an existing published
release is never replaced. Marketplace publication waits for the release gates.

Publication remains blocked until final CI, signing credentials, stable-release
approval variable and license clearance are satisfied. No signing secrets or
stable-release enablement variable are currently configured. The physical Android
CI runner is not provisioned. Rams design review could not run because its workspace
credits are exhausted. Android physical devices and other OS versions are unverified.
Concurrent/crash-recoverable installation is outside the current guarantee.
